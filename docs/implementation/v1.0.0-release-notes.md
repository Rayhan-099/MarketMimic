# MarketMimic v1.0.0 — Standalone Android Release

Welcome to the initial standalone Android release of **MarketMimic**, a personal Indian stock-market paper-trading simulator featuring an institutional-grade financial engine, local-first SQLite persistence, and an institutional financial UI.

---

### Key Features Included

- **Deterministic Financial Engine:**
  - Strict integer paise arithmetic (`₹1.00 = 100 paise`), preventing floating-point calculation drift.
  - Balanced double-entry cash ledger accounting.
  - Weighted Average Cost (WAC) delivery holdings and real-time Mark-to-Market (M2M) intraday tracking.
  - Full SEBI/exchange regulatory tax calculation (STT, Exchange turnover fee, SEBI turnover charge, Stamp duty, GST).
- **Mobile Experience (React Native & Expo):**
  - Watchlist & dynamic stock discovery with instant directional price indicators.
  - Interactive candlestick and smooth area price charts with timeframe toggling.
  - Intuitive buy/sell order tickets supporting CNC (Delivery) and MIS (Intraday) products across Market and Limit orders.
  - Order book tracking open, executed, rejected, and cancelled orders.
  - Portfolio valuation overview with cash balance, used margin, and P&L breakdown.
  - Historical tick simulation coordinator with replay controls (1x to 10x speeds).
- **Local-First & Offline Architecture:**
  - Embedded SQLite database via `expo-sqlite` and `crsqlite`.
  - Zero cloud dependencies, zero subscriptions, zero paid APIs.

### Installation Instructions

#### Direct Phone Sideloading
1. Download `MarketMimic-release.apk` directly on your Android device.
2. Tap the downloaded file in your browser or file manager.
3. If prompted to allow installation from unknown sources, tap **Settings** and enable **Allow from this source**.
4. Tap **Install** and open MarketMimic.

#### ADB Sideloading (Developers)
```bash
adb devices
adb install -r MarketMimic-release.apk
adb shell am start -n com.marketmimic.app/.MainActivity
```
